# Windows Workday

Uses the interactive signed-in user's **Notepad, File Explorer and Microsoft Edge**. No Office suite, Chrome, email account, Python or downloaded workload app is required. Start it from the Matrix Rain main display with administrator approval. The elevated worker authorizes an unelevated app helper for the exact user/session and phase; it does not run app windows under the approving administrator's identity.

## Real activity

- Creates isolated run folders under the user's Desktop and Documents: `Matrix Rain Windows Workday\<phase-id>`.
- Opens a synthetic journal in Notepad, enters varied planning text, saves it with Ctrl+S and checks the journal on disk for the new update. It never types into a personal Notepad window.
- Creates and saves different-size TXT, CSV and HTML task files across both folders, roughly 1–128 KiB each, every 45–120 seconds while the desktop is idle. These task files are generated by the helper; the journal is edited through the real Notepad window.
- Opens Explorer at the run folder and Edge with eight HTTPS website tabs, using the shared `browser-sites.json` list. The isolated test browser profile is reused across Windows Workday phases to avoid multiplying browser caches. Personal browser profiles are not used.
- Rotates confirmed foreground windows every 20–60 seconds, and advances a browser tab on its foreground turn. Reading/idle intervals leave apps open. Sites control their own refresh behavior.

Matrix Rain minimizes during app activity and returns when the app phase ends. Keep its process running. Mouse/keyboard activity or a locked/unavailable desktop pauses new typing and foreground changes until 15 seconds idle; the wall-clock deadline continues. Manual input changes the DEX observations and can interfere with automation. Use Stop before taking over the test apps.

## Requirements and cleanup

Notepad must open the test file in a **separate window**. Fresh builds with no existing Notepad windows should do this. If an existing Notepad window absorbs the file as a tab, the run fails explicitly rather than claiming or closing a personal window. Set Notepad to open files in a new window and retry. Initial OS/browser prompts or policies that block test-profile creation can also cause a visible failure; complete first-use setup and export logs if needed. A verified Explorer window is rotated when Windows exposes one; its absence does not suppress the Notepad/Edge activity.

Stop or the phase deadline closes only tagged test windows. The journal has been saved after each completed edit; generated files are retained. Cleanup reports failure if a window refuses to close, for example after manual edits create a save prompt. No personal process is killed and no test files are deleted. Do not edit those files manually during a run. Browser test profiles remain local to the signed-in user.

Export logs includes action logs and summaries under the existing local `office\<phase-id>` diagnostic tree (the legacy folder/helper name is retained), plus worker state and latest phase results. Exports contain machine/user identifiers. Windows Workday performs local file changes and ordinary web page visits; it sends no email or form submissions.
